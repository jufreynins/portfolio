Custom Web Apps

When your project needs more than WordPress

Some ideas don't fit a page builder — a browser-based tool, an internal dashboard, an automation script. I build those with modern, framework-light JavaScript and TypeScript, keeping things fast and free of unnecessary dependencies.

Browser-based tools & utilities

Self-contained tools that run entirely client-side — no server, no accounts, no data leaving the browser. The Image to WebP Converter on this site is a live, working example, not a mockup.

Internal tools & dashboards

Small, focused interfaces for internal use — admin panels, data views, or workflow tools tailored to how your team actually works, without the overhead of a full application framework.

Performance-first frontends

Built with modern, lightweight tooling (Astro, TypeScript, vanilla JavaScript) instead of defaulting to a heavy framework — smaller bundles, faster loads, and fewer moving parts to maintain.

API & third-party integrations

Connecting your site or app to the services it needs to talk to — payment processors, CRMs, automation platforms, or your own backend APIs.
