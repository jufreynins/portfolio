# Jufrey Niño Bayog — Portfolio

Personal portfolio site for Jufrey Niño Bayog, WordPress Developer & Frontend Specialist.

Built with [Next.js](https://nextjs.org) (App Router, static export) and Tailwind CSS 4.

## Commands

| Command             | Action                                     |
| :------------------ | :------------------------------------------ |
| `npm install`        | Installs dependencies                       |
| `npm run dev`        | Starts local dev server at `localhost:3000` |
| `npm run build`      | Builds the static production site to `./out/` |
| `npm run typecheck`  | Runs `tsc --noEmit`                         |
| `npm run lint`       | Runs ESLint                                 |

See `CLAUDE.md` for architecture notes.
