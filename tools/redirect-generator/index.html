# Generated redirect rules. Review before deploying to production.

Review these rules before deploying to production. This tool validates the mapping you provide, not your live server configuration.

How it works
  • Use 301 for permanent moves (most redesigns and migrations) and 302 only for temporary changes, since search engines treat them differently.
  • A "chain" warning means the destination is itself redirected elsewhere. Point the source directly at the final destination instead.
  • Bulk paste accepts "source -> destination", "source, destination", or lines separated by whitespace.
  • Always test generated rules on a staging copy of the server before deploying to production.
